# Расчёт посещаемости учебной группы

## Назначение программы

Консольная программа рассчитывает посещаемость учебной группы. Пользователь вводит название группы, общую численность студентов и количество присутствующих.

Программа определяет количество отсутствующих, процент посещаемости и категорию посещаемости, а также выводит таблицу прогноза при увеличении числа присутствующих на 1-5 человек.

После выполнения расчёта можно ввести данные другого занятия.

## Вариант

Вариант 16.

## Используемые темы Python

- Переменные и простые типы данных (`str`, `int`, `float`).
- Ввод и вывод данных: `input()` и `print()`.
- Арифметические операции.
- Условные конструкции `if`, `elif`, `else`.
- Цикл `for` и функция `range()`.
- Цикл `while`.
- Логические операторы `and` и `or`.
- Функции, параметры и `return`.
- Методы строк `strip()` и `lower()`.
- Форматированные строки (f-строки).

## Инструкция по запуску

1. Установите Python 3.14.
2. Скачайте или клонируйте репозиторий GitHub.
3. Откройте терминал в папке проекта.
4. Выполните команду:

   ```bash
   python main.py
   ```

## Глобальная константа

`WIDTH = 72` — постоянная ширина полей отчёта и таблицы. Она используется для выравнивания заголовков и данных при выводе.

## Функции и локальные переменные

### `getPositiveInteger(prompt)`

Получает положительное целое число. Параметр `prompt` содержит текст запроса. Функция повторяет ввод, пока пользователь не введёт положительное целое число, и возвращает результат.

### `getAttendance(total)`

Получает число присутствующих. Параметр `total` содержит общую численность группы. Цикл `while` проверяет, что количество присутствующих находится в диапазоне от нуля до численности группы. Функция возвращает корректное значение.

### `getCategory(percent)`

Получает процент посещаемости через параметр `percent` и возвращает категорию: «Низкая», «Средняя» или «Высокая».

### `printReport(groupName, total, present)`

Получает название группы, ее численность и число присутствующих. Рассчитывает отсутствующих, процент посещаемости и категорию, затем выводит отчёт и таблицу прогноза.

Локальные переменные функции: `absent`, `percent`, `category`, `increase`, `newPresent`, `newPercent`.

### `main()`

Управляет работой программы: получает исходные данные, вызывает функции расчёта и вывода, предлагает выполнить новый расчёт. Проверяет ответ пользователя с помощью `.strip().lower()`.

Локальные переменные: `repeat`, `groupName`, `total`, `present`.

При каждом новом расчёте исходные данные вводятся заново. Данные предыдущего занятия не сохраняются.
